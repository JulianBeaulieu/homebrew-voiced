# homebrew-voiced

Homebrew tap for [voiced](https://github.com/JulianBeaulieu/voiced), a headless
speech-to-text and text-to-speech server for Apple Silicon.

```sh
brew tap julianbeaulieu/voiced
brew install voiced
brew services start voiced
```

The formula arrives with the first tagged release of voiced. Until then this
tap is empty.
